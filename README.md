# RegionShot 0.4.7

适用 iOS 15.6 / Dopamine RootHide，arm64e。安装后重新启动 SpringBoard。

## 当前功能

- 侧边键 + 音量加或状态栏右半侧右滑进入冻结画布；拖动框选，单击不操作，未框选时双击退出；框内双击生成浮图，框外双击退出。
- 框内外拖动移动选区，角点围绕对角锚点调整；L 角标向外偏移一个物理像素。
- 浮图圆角、自由移动至屏幕外、缩放；创建时轻微放大淡入，关闭时缩小淡出，遵循减少动态效果设置。
- 冻结菜单复制全屏、选区菜单复制选区，完成后退出冻结界面；浮图复制后自动关闭当前浮图，不影响其他浮图。
- 保存、分享、扫码、标记、手动滚动长截图、截图历史、AI 图片/文字问答与 KeyboardAI 分词对接。
- 系统设置按菜单外观、功能参数、截图记录、入口诊断分组；功能参数按截图保存、浮图、历史、长图、AI 分页。左上角返回上一页，菜单排序位于右上角。
- 三类菜单独立排序、功能开关、自定义名称与图标；升级保留剩余按钮的原有定制。

0.4.2 已删除 OCR、翻译、隐藏浮图和恢复隐藏浮图的功能实现、菜单入口及参数。扫码与 AI 问答保留。0.4.1 的独立像素裁剪、取消吸边和浮图移动边界限制继续保留。

## 构建与检查

GitHub Actions 使用固定版本 RootHide Theos 和 iOS 15.6 SDK，检查像素裁剪、菜单升级兼容、参数校验、历史持久化、几何、流式响应、长图对齐、扫码、安装包及 arm64e ABI。动画观感及系统边缘手势需实机验证。

自动滚动长截图与完整编辑器仍在开发中。

## 0.4.7 修复

- 长按菜单打开和关闭期间保留浮窗阴影，不再等预览回缩完成后才重新出现。
- 冻结选区窗口与浮窗根控制器支持横竖屏旋转，横屏截图保持原始宽高比例。
- 选区拖动与系统顶部手势改为互斥，避免从刘海两侧开始滑动时被通知中心或控制中心中断。
- 冻结菜单和选区菜单中的“取消”允许关闭，不再强制开启。

## 0.4.4 修复

- 冻结窗口启用与 ShellX 相同的屏幕边缘延迟识别器，并继续在冻结期间阻止 SpringBoard 系统下拉手势接收触摸；顶部开始框选时不再由通知中心或锁屏下拉抢走触摸。
- 冻结/选区菜单改为系统深色磨砂材质，透明度可在“截图与保存”中调节；图标顶部、图标与文字、文字底部间距缩小。
- 选区菜单增加“保存”，保存行为与“仅复制”及“复制 + 保存”设置联动，完成后退出冻结界面。
- 长按菜单只预览内部圆角图片，不再让带阴影的浮图外壳参与菜单返回动画，避免关闭菜单后阴影回弹。

## 0.4.6 修复

- 顶部状态栏附近的选区拖动改由连续拖动手势接管，避免滑动中途被系统边缘手势取消。
- AI 服务、模型抓取、API Key、人物管理、悬浮球、主题和流式输出整合到 AI 设置页。
- 浮窗承载层改为透明，开关动画与长按菜单期间关闭阴影，消除黑幕、黑影和黑色裂缝。

## 0.4.5 修复

- 四个 L 形角标的转角和两端均改为圆润线帽。
- L 角标内缘与细选区边框保持至少 1 个显示点的间隔，在 Retina 屏幕上仍清晰可见；实际裁剪矩形不变。
- AI 卡片改为屏幕中央约 56% 高度、左右 20 点边距；顶部控制按钮增加间距，底部调整为输入框、添加图片、发送的顺序，回复操作按钮靠右排列。图片和消息样式、请求逻辑保持原样。


## 0.4.3 修复

浮图外壳改用 UIView，图片独立裁剪，圆角缩小为 5 点，避免 UIImageView 外壳的图片绘制覆盖圆角。菜单高亮与退出使用相同圆角预览，菜单生命周期内暂停双击关闭识别。

L 角标向外移动距离包含半个线宽，让线条内缘与实际选区间隔一个物理像素。冻结菜单的截屏按钮按保存设置直接保存/复制全屏；选区菜单截图和框内双击仍生成浮图。

冻结界面显示时，拦截 SBSystemGestureManager 的 shouldSystemGestureReceiveTouchWithLocation:，阻止系统下拉手势接收触摸。安装前检查运行时方法签名，退出冻结界面即恢复原处理；长截图滚动阶段不拦截。接口依据运行时头文件，iOS 15.6 上是否挂接及触摸表现需实机验证。
